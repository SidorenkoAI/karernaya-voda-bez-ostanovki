# Карьерная вода без остановки

Проект для **Инженерного кубка 2026–2027** (конкурс «Создатели будущего»), кейс 16 компании **СУЭК**, направление «Гидравлика и управление водными потоками».

Учебная концепция водоотлива, накопления, очистки и повторного использования воды **Восточно-Бейского разреза** (ООО «Восточно-Бейский разрез», СУЭК, Бейский район Республики Хакасия) при росте притока с 450 до 1000 м³/ч, с проверкой суточного пика, отказа откачки и экономики модернизации.

**Симулятор онлайн:** https://sidorenkoai.github.io/simulyator-vodootliva/ (отдельный публичный репозиторий [simulyator-vodootliva](https://github.com/SidorenkoAI/simulyator-vodootliva), открывается из РФ без VPN)

## Главные результаты

|---|---|

| Накопитель | полезный объём 2500 м³, полный 3647 м³, глубина 4,5 м, 1054 м² из 1200 |
| Пик / отказ 2 ч | максимум 531 м³, возврат к 9-му часу / восстановление за 18 ч (норма 24 ч) |

| Экономика | A дешевле альтернативы 3 × P1 на 10,8 млн руб. за 5 лет |
| Повторная вода | +37,4 млн руб. за 5 лет, окупаемость 1,8 года; потребитель — обогатительная фабрика разреза |
| Стресс-тест | запас A по притоку 2,6 %; рекомендация — строить A с местом под P1 (переход к 2 × P2 + P1) |

## Как пересобрать

Нужны Python 3.12+ и LibreOffice (для пересчёта формул и экспорта в PDF).

```bash
pip install openpyxl python-pptx python-docx matplotlib pymupdf pillow
python build_all.py
```

`build_all.py` по порядку собирает основную книгу и пересчитывает её, затем книгу дополнения, презентацию (PPTX → PDF), пояснительную записку (два прохода, чтобы проставить номера страниц в оглавлении) документ дополнения и принципиальную гидравлическую схему (`Дополнение/build_scheme.py`). Решения команды (тип насосов, полезный объём, уровни, технология доочистки) меняются на листе «Решения» основной книги или в начале скриптов.

## Как обновить онлайн-симулятор

После правки `Симулятор/Симулятор_офлайн.html` скопируйте его как `index.html` в публичный репозиторий `simulyator-vodootliva` (лежит рядом с папкой проекта), затем закоммитьте и отправьте:

```bash
cp Симулятор/Симулятор_офлайн.html ../simulyator-vodootliva/index.html
cd ../simulyator-vodootliva && git commit -am "Обновление симулятора" && git push
```

GitHub Pages пересоберёт сайт примерно за минуту.

## Что осталось заполнить

ФИО авторов, организация, город и название команды — заглушки в начале `build_presentation.py` и `build_report.py` (переменные `TEAM`, `AUTHORS`, `ORG`, `CITY`, `YEAR`), затем `python build_all.py`.

## Ограничения

Все числа кейса — единые учебные условия, а не измерения разреза. Открытые данные о Восточно-Бейском разрезе (дата обращения 07.11.2026) используются для проверки правдоподобия и выбора потребителя повторной воды; фактический приток, состав воды и требования обогатительной фабрики к воде нужно получить на этапе пилота.
